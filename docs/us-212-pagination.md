# US-212 — Pagination des lignes riches

`atelier_text_layout::pagination::paginate` paginates `ParagraphLayout` values already produced by US-210. It preserves input paragraph and line indices and returns one placement for each input line. `PlacedLine::top` and `baseline` are coordinates local to the page; dimensions and spacing use 1/64 typographic point. Source offsets remain on the original `LayoutLine` and therefore remain UTF-8 byte offsets.

The caller supplies one `ParagraphRules` for each layout. Rule spacing must match the before/after spacing already included in `ParagraphLayout::height`; the paginator checks `height = before + sum(line heights) + after`, then removes paragraph spacing from line placement so it is not counted twice. Rules are independent from `ParaProps` and do not mutate the model.

Adjacent paragraph spacing is the maximum of the preceding `space_after` and following `space_before`. When both paragraphs have the same `style_id`, contextual spacing subtracts the corresponding side from that maximum, clamped at zero. For example, after 200 twips and before 240 twips resolve to 240 twips normally, to 40 twips when only the preceding paragraph has contextual spacing, and to zero when both do. Twips must be converted to 1/64 pt by the caller.

An automatic page break drops the next paragraph's before spacing at page top. `break_before` and a pending `break_after` preserve it. If explicit before spacing consumes or exceeds the page, pagination keeps that offset, makes finite progress, and reports `ParagraphSpacingExceedsPage`; resulting lines can sit beyond the page box. Caret adaptation uses the returned page index and page-local `top`; glyph rendering uses the translated `baseline`. A view must not infer a page from the vertical coordinate alone; it may clip out-of-page positions according to its viewport policy.

Explicit `break_before`, `break_after`, and `line_breaks_before` boundaries take precedence over keep and widow/orphan rules. A conflicting keep or widow/orphan rule is relaxed with a diagnostic, and a keep chain stops at each explicit boundary; backtracking never moves a line across a manual break. Otherwise, the deterministic order is: move a fitting keep chain or keep-together paragraph to the next page; fit lines greedily; adjust a split to satisfy widow/orphan minima when possible; then make progress with a relaxation diagnostic for impossible constraints. `break_after` does not create a trailing empty page, including when empty layouts follow it. Each `line_breaks_before` value is a zero-based line index strictly between the first and terminal positions: zero, the terminal index, duplicates, and out-of-order indices are rejected.

`ParagraphLayout::height` must equal the exact integer sum `space_before + sum(line heights) + space_after`; no rounding tolerance is applied. `keep_together`, `keep_with_next`, and widow/orphan minimums are honored when they fit; impossible constraints are relaxed with diagnostics. A line taller than a page is retained once, at page top when explicit spacing does not offset it, and reported. `max_pages` and `max_work` bound resource use; invalid inputs return a typed error and no partial pagination.

The contextual spacing rule follows the [Microsoft Open XML documentation](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.wordprocessing.contextualspacing?view=openxml-3.0.1). This specifies an input rule, not evidence of matching a Word document corpus.

The numerical tests cover spacing, page-local coordinates, manual and paragraph breaks, keep precedence, widow/orphan diagnostics, overheight lines, conservation, and malformed input. No authentic Word corpus comparison is included, so the 95% fidelity target has not been measured and US-212 remains partial.
