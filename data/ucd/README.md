# Unicode Character Database

The frozen source corpus is Unicode 17.0.0 in `17.0.0/`. It was extracted
from the official archive at https://www.unicode.org/Public/17.0.0/ucd/UCD.zip.
The archive used is retained locally at `target/prototype-oracle/UCD-17.0.0.zip`
and its SHA-256 is recorded in `17.0.0/manifest.json`. Original archive file
bytes are preserved; `LICENSE.txt`, `README.md`, and `manifest.json` are
additional provenance files.

The Unicode License V3 applicable to the data is included as `17.0.0/LICENSE.txt`.
