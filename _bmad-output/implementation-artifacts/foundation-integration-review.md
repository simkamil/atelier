## Limites maintenues

US-004 reste partielle : le contrôle mémoire porte sur la taille de sortie déclarée par la cible, pas sur ses allocations réelles. Les références CFF sont synthétiques et leur oracle indépendant ne couvre ni CID ni FontMatrix. Les références CFB sont deux petits conteneurs natifs, pas un corpus de documents Word. Les PNG raster sont des bases de régression. US-210 attend Word et les API riches ne sont pas encore raccordées à l'interface TXT. Les tests musl sont compilés sur Windows, sans exécution Linux locale. La CI distante doit être constatée séparément après push.
